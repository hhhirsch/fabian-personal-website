# fabian-delugas-website

Leeres Website-Grundgerüst mit Next.js (App Router), TypeScript und Tailwind CSS.

```bash
npm install
npm run dev
```

Die Entwicklungsseite ist unter http://localhost:3000 erreichbar. `npm run lint`
prüft den Code und `npm run build` erstellt den Produktions-Build.

Metadaten und Telefonnummer sind Platzhalter; die verlinkten Seiten für Impressum
und Datenschutz müssen noch erstellt werden.
